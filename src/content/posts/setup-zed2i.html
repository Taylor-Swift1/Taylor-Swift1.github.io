This is the instruction to setup ZED2i camera.

  1. Install Anaconda to build the python environment with 3.9.0
  2. Install CUDA 11.7
  3. Install matched version of ZED2i SDK. We use 3.8.2 here.
  4. Run the example code to detect skeletons
